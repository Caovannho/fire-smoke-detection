Bước 5: Kiểm tra dataset sau khi setup
python -c "
import os
for split in ['train', 'val', 'test']:
    d = f'data/{split}/labels'
    files = os.listdir(d)
    empty = [f for f in files if os.path.getsize(os.path.join(d, f)) == 0]
    print(f'{split}: {len(files)} files, {len(empty)} rỗng (None), {len(files)-len(empty)} có nhãn')
"
Kết quả mong đợi:
train: 14122 files, 6458 rỗng (None), 7664 có nhãn
val: 3099 files, 1375 rỗng (None), 1724 có nhãn
test: 4306 files, 2005 rỗng (None), 2301 có nhãn
💡 Lưu ý về file label rỗng:
D-Fire có ~46% ảnh "None" (không có lửa/khói). Đây là
negative samples
giúp model phân biệt lửa thật với áo đỏ, đèn vàng, hoàng hôn. File label rỗng (0 KB) là
đúng thiết kế
, không phải lỗi.
